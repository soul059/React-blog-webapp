# Blog Web App

A user-friendly blog app designed to help you share your thoughts, stories, and ideas with the world. Whether you’re a seasoned blogger or just starting out, **Blog by Soul** offers a seamless experience with its intuitive interface and good features.

## Key Features

- **Login/Signup:** You can login/signup for use.
- **React with Appwrite Backend:** It’s done by react with appwrite backend.
- **Real-Time Editor:** In add post you can edit content by real-time editor.
- **Image Upload:** You also can add image to post.

Visit [Blog by Soul](https://react-blog-webapp.vercel.app/)
